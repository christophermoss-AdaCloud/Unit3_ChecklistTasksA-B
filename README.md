CHECKLIST - Learning Aim A: Design a digital portfolio & Learning Aim B: Create and test a digital portfolio

## Learning Aim A: Design a digital portfolio

- [ ] Define portfolio purpose and target audience
- [ ] Gather and organise portfolio content (text, images, media)
- [ ] Produce a site map or page structure
- [ ] Create wireframes/layout plans for key pages
- [ ] Choose a consistent visual style (fonts, colours, spacing)
- [ ] Plan accessibility features (alt text, readable contrast, navigation)

## Learning Aim B: Create and test a digital portfolio

- [ ] Build the portfolio pages using the agreed design
- [ ] Add navigation links and ensure all pages are reachable
- [ ] Optimise media and check page loading performance
- [ ] Test functionality (links, media, layout behaviour)
- [ ] Test on multiple devices/screen sizes and browsers
- [ ] Fix identified issues and re-test
- [ ] Collect feedback and record improvements made
